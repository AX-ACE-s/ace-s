# 우리동네 대형폐기물 AI 수거비용 산정 및 자동 분류

청년 공공AX 서포터즈 3차 활동 개발 결과물입니다. 버릴 물건의 품목·규격을 확인하면 **예상 수수료와 산정 근거(지역·품목·규격·데이터 기준일·출처)**를 보여 주는 웹서비스입니다.

## 현재 구현 범위

| 필수 기능 | 담당 | 상태 |
|---|---|---|
| 수수료 산정 및 근거 안내 | 정하영 | 구현 완료 (`core/fees.py`) |
| 사진 기반 품목 인식·근거 제시 | 박상훈 | 연동용 구현 포함(`core/vision.py`, `/api/identify`) — 팀 구현으로 교체 가능 |
| 지역 기준 맞춤 규격 질문·실측 보정 | 강문정 | 규격 질문 API(`/api/spec-question`)와 실측 판정 로직 제공 |
| 배출 전 체크리스트·신청 연결 | 박지윤 | 별도 모듈로 연동 예정 |

## 수수료 산정 기능

- 공공데이터포털 `전국대형폐기물수거수수료정보표준데이터` CSV를 읽어 지자체·품목·규격별 수수료를 조회합니다. CP949/UTF-8 인코딩과 컬럼명 차이를 허용하고, 금액이 비었거나 품목이 없는 행은 건너뜁니다.
- 규격이 `1m 이상 2m 미만`, `400L 이상` 같은 범위형이면 **실측값(cm, L, kg, 인치)으로 규격을 자동 판정**합니다. 경계값은 이상/미만 기준으로 처리합니다.
- 규격이 하나뿐인 품목은 추가 질문 없이 바로 산정하고, 여러 개일 때만 질문합니다.
- 결과에는 항상 지역·품목·규격·규격 결정 방식·데이터 기준일·제공기관·출처 URL을 함께 표시합니다.
- 조례 별표(수수료 표) 원문 링크: 법제처 자치법규 Open API 별표 목록에서 지자체별 링크(`data/ordin_links.json`, 약 170개 지자체)를 만들어 근거 영역에 표시합니다(`python scripts/build_ordin_links.py`). 금액 자동 대조는 미구현입니다(별표 본문이 한글 문서 뷰어로만 제공됨).
- 여러 품목을 담아 합계를 계산할 수 있습니다.
- **근거를 '나열'에서 '비교와 설명'으로** (`FeeTable._enrich`):
  - *다른 규격과 비교*: 같은 품목의 다른 규격 금액과 차액(`+4,000원`)을 표로 보여 주고, 잘못 신고했을 때의 최대 차이를 알립니다. 금액이 확정되지 않은 규격은 차액 계산에서 제외합니다. 단가형(`1㎡당`)은 총액과 비교할 수 없어 제외합니다.
  - *경계값 주의*: 실측값이 규격 경계의 ±5% 안이고 반대편이 다른 규격이면 "조금만 달라도 다른 규격·금액이 될 수 있다"고 알립니다(`core/specs.py: boundary_check`).
  - *쉬운 설명 문장*: 왜 이 규격·금액인지, 기준일·제공기관, 충돌·표기 모순·오래된 기준일일 때의 안내를 한 문단으로 만듭니다.
  - *근거 복사*: 지역·품목·규격·금액·설명·비교·출처·안내 문구를 한 번에 복사합니다(신고·문의 때 붙여 넣기용).
- 자연어/별칭/오타 매칭을 지원합니다(예: 쇼파→소파, TV→텔레비전).

## 데이터 (공공데이터포털 오픈API 연동)

앱은 **공공데이터포털 오픈API**(`tn_pubr_public_lar_was_fee_api`)에서 수수료 데이터를 받아 사용합니다.

- 인증키를 환경변수 `DATA_GO_KR_KEY`로 설정하고 `python app.py`를 실행하면, 서버가 시작될 때 **백그라운드에서 API로 전체 데이터(약 2만 3천 건)를 받아** `data/fees.csv`에 저장하고 메모리의 표를 교체합니다. 받는 동안에는 기존 데이터(없으면 시연용 샘플)로 서비스하며, 진행 상황은 `/api/health`의 `progress`로 확인할 수 있습니다.
- `data/fees.csv`가 `FEE_REFRESH_DAYS`(기본 7일)보다 오래되면 다음 실행 때 자동으로 다시 받습니다. `FEE_REFRESH_DAYS=0`이면 매번 새로 받습니다.
- 요청마다 API를 호출하지 않고 저장해 두고 쓰는 이유: 전체 조회에 약 230회 호출이 필요해 느리고 일일 호출 한도가 있기 때문입니다.
- **인증키가 없거나 API 호출이 실패하면** 저장소에 포함된 `data/fees.csv`(받아 둔 스냅샷)로, 그것도 없으면 시연용 `data/fees_sample.csv`(가상 지자체)로 동작합니다.
- 수동으로 받으려면 `python scripts/fetch_fees.py` (`--max-pages 2` 같은 시험 실행은 `data/fees_partial.csv`에 저장되어 앱에 영향을 주지 않습니다).

```bash
# Windows (cmd)
set DATA_GO_KR_KEY=인증키
python app.py
```

인증키는 저장소에 넣지 않습니다(환경변수로만 사용).

## 사진 인식 → 직접 검색 흐름

1. 지역을 **검색**해서 고릅니다(시·군·구 이름 일부만 입력).
2. 물건 사진을 올리면 AI가 **해당 지자체 수수료표에 있는 품목 중에서만** 후보(최대 3개)와 관찰 근거를 추천합니다.
3. 추천이 맞으면 누르고, 맞지 않거나 사진이 없으면 **직접 검색하거나 목록에서 선택**합니다.
4. 이후 규격 확인 → 수수료·근거 안내로 이어집니다.

- AI 인식은 환경변수 `ANTHROPIC_API_KEY`가 있을 때만 동작합니다(모델은 `ANTHROPIC_MODEL`로 변경 가능, 기본 `claude-sonnet-5-5`). 키가 없거나 실패하면 "직접 검색해 주세요"로 안내하고 수수료 안내는 그대로 동작합니다.
- AI가 목록에 없는 품목을 지어내면 서버에서 버립니다. 인식 결과는 **추천일 뿐이며 사용자가 확정**합니다.
- 사진은 서버에 저장하지 않고 인식 요청에만 사용합니다(외부 AI API로 전송됨). 사람 얼굴이나 개인정보가 찍힌 사진은 올리지 마세요.
- 파일은 내용(매직 넘버)으로 JPG/PNG/WEBP/GIF만 허용하고 5MB로 제한합니다.

## 모듈 구성과 역할 경계

| 파일 | 역할 | 담당 |
|---|---|---|
| `core/fees.py` | **수수료 산정·근거 안내**: 확정된 (지자체·품목·규격)으로 수수료 조회, 근거 표시, 금액 충돌·모순·오래된 기준일 처리, 합계 | **기능③ 정하영** |
| `core/api_client.py`, `scripts/` | 공공데이터포털 API 수집·갱신, 데이터 품질 리포트 | 기능③ |
| `core/specs.py` | 규격 문구 해석·실측값 판정·단위 검증 — **기능②(규격 질문·실측 보정)와의 접점**. 기능③ 단독 시험을 위한 임시 구현이며, 팀의 기능② 모듈로 교체·연결한다 | 기능② 연동 |
| `core/vision.py` | 사진 기반 품목 추천 — 기능①과의 접점(임시 구현) | 기능① 연동 |

**기능③의 입출력**: 입력 = 지자체(`region_id`), 품목, **확정된 규격**(단가형은 크기도) → 출력 = 금액과 근거(지역·품목·분류·규격·결정 방식·기준일·제공기관·출처).
`FeeTable.calculate(region_id, item, spec=...)`. 기능②가 규격을 확정해 넘기면 그대로 이어진다.

## 수수료 산정의 안전장치 (기능③)

- **같은 규격에 서로 다른 금액이 등록된 경우** 임의로 하나를 고르지 않습니다. "금액 확인 필요(최소~최대)"와 후보 금액(기준일·분류 포함)을 보여 주고 지자체 확인을 안내하며, 합계에서는 제외합니다. 같은 금액의 중복 행은 충돌로 보지 않습니다.
- **유료/무료 표기와 금액이 모순인 행**(예: "무료"인데 3,000원)은 확정하지 않고 지자체 확인을 안내합니다.
- **데이터 기준일이 1년 넘게 지난 행**은 결과에 "현재 금액과 다를 수 있음" 경고를 덧붙입니다.
- 공백만 다른 규격(`모든규격`/`모든 규격`)은 같은 규격으로 묶습니다. 무료(0원)는 "무료"로 표시합니다.
- `1㎡당` 같은 단가형은 크기를 받아 단위 올림으로 계산하며 "추정"으로 표시합니다.
- **원본 전 행 재조회 검증**: `pytest`가 데이터의 모든 (지자체·품목·규격)을 다시 조회해 원본 `fee`와 일치하는지(충돌은 충돌로 표시되는지), 그리고 비교표의 다른 규격 금액·차액이 원본과 맞는지 확인합니다. `data/fees.csv`가 있으면 전체를 검증합니다(약 1초).
- `python scripts/data_report.py`: 지자체·품목 수, 규격 유형 분포, 충돌·모순 건수, 무료 비율, 기준일 범위를 출력합니다(결과보고서 근거 수치용).

## 규격 처리 (기능② 연동 접점, `core/specs.py`)

규격 질문·실측 보정은 기능②의 일입니다. 아래는 기능③을 단독으로 시험하기 위한 임시 구현이며, 기능②와 합칠 때 교체합니다.
확실한 경우만 숫자 구간으로 해석하고, `3인용(폭 1.8m 이하)`, `90*100미만`처럼 불확실하거나 모순인 표기는 선택형으로 남깁니다. 실측값은 단위별 현실적인 범위(예: 길이 10~1000cm)를 벗어나면 단위를 안내하고 판정하지 않습니다.

## 실제 데이터 대응 사항 (오픈API 응답 기준)

- 컬럼: `ctpvNm`(시도) `sggNm`(시군구) `larWasNm`(품목) `larWasSeNm`(분류) `larWasSpcfct`(규격) `paidFreeYn`(유/무료) `fee` `crtrYmd`(기준일) `mngInstNm`(관리기관). 포털 CSV의 한글 컬럼명도 인식합니다.
- 규격 표기가 지자체마다 달라 다음을 모두 해석합니다: `㎝/㎡` 기호, `높이1m이상`(공백 없음), `264㎡ 형 이상`, `1m 이상 ~ 2m 미만`, `3인용이상`, `높이 또는 폭(큰수)` 같은 측정 기준 문구.
- 구간이 겹치는 규격(`300L 이상`, `500L 이상`)은 가장 좁고 높은 구간을 선택합니다.
- `모든규격`, `업소용`, `좌변기` 등 범위가 아닌 규격은 선택지로만 제공하고, 무료 품목(`fee=0`)은 "무료"로 표시합니다.
- `1㎡당` 같은 단가형은 크기를 입력받아 단위 올림으로 **추정**합니다(지자체별 실제 산정 방식은 확인 필요).
- 지자체마다 `데이터 기준일`이 달라(예: 2025-12 ~ 2026-09) 화면에 행별 기준일을 그대로 표시합니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/regions` | 지자체 목록 |
| GET | `/api/items?region=&q=` | 품목 목록 또는 자연어 매칭 |
| GET | `/api/spec-question?region=&item=` | 규격 선택지와 실측 입력 단위 |
| POST | `/api/identify` | multipart(`image`, `region`) → 품목 후보(추천) |
| POST | `/api/fee` | `{region,item,spec?,measure?}` → 금액+근거 (+`alternatives`,`max_gap`,`boundary_warning`,`explanation`,`copy_text`) |
| POST | `/api/fee/total` | `{region,entries:[{item,spec}]}` → 합계 |

## 보안·개인정보

- 이 모듈은 외부 API 키가 필요 없습니다. 이후 AI·기상청 연동 시 키는 환경변수로만 관리하고 `.env`는 커밋하지 않습니다.
- 사용자 입력은 서버에서 모두 검증하며 화면은 `textContent`로만 출력합니다.

## 한계

- 표준데이터에 없는 지자체·품목은 조회할 수 없습니다.
- 주소 검색 API 연동은 미구현이며 지역은 목록에서 선택합니다.
- 표시 금액은 예상 금액이며 실제 금액은 지자체 신청 시 확정됩니다.
- 규격이 두 가지 이상의 기준(예: 폭+높이)으로 나뉘는 품목은 아직 지원하지 않습니다.
